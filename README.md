## 📖 Overview

Welcome to **AI-ProjectX**. This repository serves as a centralized hub for a diverse collection of projects focused on **Artificial Intelligence (AI), Automation, and Intelligent Systems**.

The primary objective of this repository is to explore, experiment, and implement various forms of AI technologies—ranging from Machine Learning and Natural Language Processing (NLP) to Process Automation and Generative AI.

Each directory within this repository represents a standalone project or a specific module designed to solve particular problems or demonstrate specific AI capabilities.

## 🚀 Getting Started

Since this is a mono-repo containing multiple independent projects, installation and usage depend on the specific project you wish to run.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Thanarat-Int/AI-ProjectX.git](https://github.com/Thanarat-Int/AI-ProjectX.git)
    ```
2.  **Navigate to the specific project directory:**
    ```bash
    cd "AI Brain Auto Form"
    # or any other project folder
    ```
3.  **Follow the `README.md` within that specific folder** for setup and execution steps.
