# Example Procedure: Incident Response

## Overview
This procedure outlines the steps to follow when a data incident is detected.

## Steps
1. Identify and classify the incident severity.
2. Contain the issue and collect evidence.
3. Notify the security team within 30 minutes.
4. Prepare a summary report within 24 hours.
