# 🚀 AI Resume Screener & Interview Assistant
**ระบบคัดกรองใบสมัครงานอัจฉริยะระดับโลก (World-Class Intelligent Recruitment System)**

---

## 📖 ภาพรวมโปรเจกต์ (Project Overview)

โปรเจกต์นี้คือ **ระบบคัดกรองใบสมัครงานอัจฉริยะด้วย AI** ที่ออกแบบมาเพื่อลดภาระงานของฝ่ายบุคคล (HR) ระบบช่วยวิเคราะห์ Resume แบบอัตโนมัติ ให้คะแนนความตรงตาม Job Description และแสดงผลลัพธ์เชิงลึกเพื่อช่วยในการตัดสินใจ สร้างด้วย Python และ Streamlit พร้อมหน้าตา UI ระดับ Production ที่มีฟีเจอร์ล้ำสมัย เช่น โหมดปิดกั้นอคติ (Blind Hiring), โหมดเปรียบเทียบผู้สมัคร (Battle Mode), และระบบส่งอีเมลอัตโนมัติ

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 🧠 ระบบสมองกลแบบลูกผสม (Hybrid AI Engine)
เราใช้เทคโนโลยี AI สองรูปแบบทำงานร่วมกันเพื่อให้ได้ผลลัพธ์ที่ดีที่สุด:
- **Rule-Based Engine (พื้นฐาน & เร็ว)**: ใช้ระบบจับคู่คำค้น (Keyword Matching) และ Regex จากฐานข้อมูลกว่า 150+ ทักษะ ครอบคลุมทั้งสายไอที, ธุรกิจ, และออกแบบ ช่วยในการให้คะแนนทักษะแข็ง (Hard Skills) ได้อย่างแม่นยำ 100%
- **Gemini LLM Engine (อัจฉริยะ)**: ใช้ AI ระดับสูง (Google Gemini Pro) เพื่อวิเคราะห์ความหมายเชิงลึก (Deep Semantic Analysis) สรุปจุดเด่น-จุดด้อย และสร้างคำถามสัมภาษณ์เฉพาะบุคคล (Personalized Interview Questions)

### 2. 📂 ระบบตรวจทีละหลายคน & ตารางจัดอันดับ (Bulk Screening & Leaderboard)
รองรับการอัปโหลด Resume พร้อมกันหลายไฟล์ (Drag & Drop) ระบบจะประมวลผลและจัดอันดับผู้สมัครแบบ Real-time ลงในตาราง Leaderboard พร้อมแถบสีบอกระดับคะแนน ทำให้เห็นภาพรวมได้ทันทีว่าใคร "ผ่าน" หรือ "ไม่ผ่าน"

### 3. 🎯 พรีเซ็ตแผนก & การถ่วงน้ำหนักคะแนน (Department Presets & Dynamic Weighting)
มีชุดคำสั่งสำเร็จรูปสำหรับแผนกต่างๆ เช่น ฝ่ายขาย (Sales), วิศวกรรม (Engineering), บัญชี (Finance), และทรัพยากรบุคคล (HR) ช่วยให้ HR ไม่ต้องพิมพ์คำค้นหาเอง พร้อมระบบ "Essential Skills" กำหนดทักษะจำเป็นเร่งด่วนที่จะมีคะแนนคูณสอง เพื่อเน้นคนที่ตรงสเปกที่สุด

### 4. 🙈 โหมดคัดเลือกแบบปิดกั้นอคติ (Blind Hiring Mode)
สวิตช์เปิด-ปิดการแสดงชื่อผู้สมัคร โดยจะเปลี่ยนชื่อเป็นรหัส (เช่น Candidate #1) เพื่อให้การตัดสินใจเลือกคนมาจาก "ฝีมือ" ล้วนๆ ช่วยลดอคติแฝง (Unconscious Bias) ในการจ้างงาน

### 5. ⚔️ สังเวียนเปรียบเทียบผู้สมัคร (Comparison Battle Arena)
เครื่องมือเปรียบเทียบผู้สมัครแบบ "หมัดต่อหมัด" นำผู้สมัคร 2 คนมาวางคู่กันเพื่อดูคะแนน, ทักษะ, และกราฟวิเคราะห์อย่างชัดเจน ช่วยให้เลือกคนที่ดีที่สุดได้ง่ายขึ้นในกรณีที่คะแนนใกล้เคียงกัน

### 6. 📧 ระบบอีเมลอัจฉริยะ (Smart Email Actions)
ปุ่มลัดสำหรับ "เชิญสัมภาษณ์" หรือ "ปฏิเสธ" ระบบจะร่างเนื้อหาอีเมลให้อัตโนมัติพร้อมส่ง ช่วยให้ HR สื่อสารกับผู้สมัครได้รวดเร็วทันใจโดยไม่ต้องพิมพ์ใหม่ทุกครั้ง

### 7. 📊 ประวัติและวิเคราะห์ข้อมูล (Historical Analytics)
บันทึกประวัติการใช้งานทั้งหมดไว้ในระบบ สามารถดูย้อนหลัง, ส่งออกเป็นไฟล์ Excel/CSV, ดูแผนภาพ Heatmap, หรือลบประวัติทิ้งได้ทันทีเพื่อความปลอดภัยของข้อมูล

## 🛠️ สถาปัตยกรรมทางเทคนิค (Technical Architecture)

โปรเจกต์นี้ถูกออกแบบด้วยสถาปัตยกรรมแบบ **Modular Monolith** โดยเลือกใช้ Tech Stack ที่ทันสมัยดังนี้:

### 1. Frontend & UI: **Streamlit**
   - **หน้าที่**: เป็นหน้าด่านหลัก (User Interface) ทั้งหมดที่ผู้ใช้เห็น
   - **เหตุผล**: สวยงาม ทันสมัย รองรับ Responsive (ใช้บนมือถือได้) และทำงานร่วมกับ Python ได้อย่างไร้รอยต่อ

### 2. Logic & Processing: **Python 3.10**
   - **หน้าที่**: ภาษาหลักในการประมวลผล เปรียบเสมือน "หัวใจ" ของระบบ
   - **เหตุผล**: เป็นภาษามาตรฐานโลกสำหรับงาน AI และ Data Science มี Library สนับสนุนครบครัน

### 3. Data Processing: **Pandas**
   - **หน้าที่**: จัดการข้อมูลตาราง (DataFrame)
   - **การใช้งาน**: ใช้สร้าง "Leaderboard" จัดเรียงลำดับคะแนน, กรองข้อมูล, และเตรียมไฟล์ CSV

### 4. Visualization: **Plotly**
   - **หน้าที่**: สร้างกราฟและแผนภาพโต้ตอบได้ (Interactive Charts)
   - **การใช้งาน**: ใช้สร้างกราฟแท่งเปรียบเทียบในโหมด Battle และกราฟ Heatmap

### 5. AI & NLP Engine (สมองกล):
   - **Google Gemini Pro (Generative AI)**: ทำหน้าที่เหมือน "HR อาวุโส" อ่าน Resume เพื่อสรุปใจความและคิดคำถามสัมภาษณ์ (ใช้เทคนิค Direct Prompting / Full Context Injection)
   - **ReGex & Keywords (Rule-Based)**: ทำหน้าที่เหมือน "เครื่องสแกนความเร็วสูง" สแกนหา Hard Skills อย่างแม่นยำ

### 6. File Parsing: **pdfplumber & python-docx**
   - **หน้าที่**: "ล่าม" แปลภาษาเอกสาร
   - **การใช้งาน**: แกะตัวหนังสือออกจากไฟล์ PDF และ Word (.docx) ให้กลายเป็น Text เพื่อส่งต่อให้ AI

### 7. Database: **SQLite**
   - **หน้าที่**: หน่วยความจำระยะยาว (Long-term Memory)
   - **เหตุผล**: เป็น Database แบบไฟล์ (Serverless) พกพาโปรเจกต์ไปรันที่ไหนก็ได้ทันที และเก็บข้อมูลไว้ในเครื่อง (Local Privacy)

## 🚀 วิธีใช้งาน (How to Run)

1.  **ติดตั้งไลบรารี (Install Dependencies)**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **รันโปรแกรม (Run Application)**:
    ```bash
    streamlit run app.py
    ```
3.  **เข้าใช้งาน**: เปิดเบราว์เซอร์ไปที่ `http://localhost:8501`.
