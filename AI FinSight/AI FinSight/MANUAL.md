# manual.md - คู่มือแนะแนวโปรเจกต์ FinSight AI

## 1. โปรเจกต์นี้สร้างมา "ทำไม"? (Why FinSight?)

โปรเจกต์นี้ถูกสร้างขึ้นเพื่อ **"จำลองสถานการณ์จริง" (Real-world Simulation)** ของการทำงานในตำแหน่ง **AI Engineer** ที่ SCBX หรือบริษัท Tech ชั้นนำครับ โดยมีเป้าหมายเพื่อพิสูจน์ทักษะ 3 ด้าน:

1.  **AI Integration (การผสมผสาน AI):** ไม่ใช่แค่ใช้ ML ทำนายตัวเลข (Quantitative) แต่ใช้ LLM (Gemini) มาช่วยวิเคราะห์เหตุผลและเขียนรายงาน (Qualitative) เหมือนมีนักวิเคราะห์ส่วนตัว
2.  **Scalable Architecture (โครงสร้างที่ขยายได้):**
    *   เราไม่ได้เขียนโค้ดมั่วๆ รวมกันในไฟล์เดียว
    *   แต่เราแยก **"สมอง" (Backend API)** ออกจาก **"หน้าตา" (Frontend Dashboard)** อย่างชัดเจน
    *   นี่คือท่ามาตรฐานที่ใช้กันใน Netflix, Uber, SCBX เพื่อให้ทีมทำงานร่วมกันได้ (Dev, Data Scientist, UX/UI)
3.  **End-to-End Delivery:** ตั้งแต่การดึงข้อมูลดิบ -> แปลงข้อมูล -> เข้าโมเดล -> แสดงผล -> ทำ UI ให้สวยงามน่าใช้

---

## 2. โครงสร้างระบบ (System Architecture)

-   **Backend (`src/api/main.py`):** เปรียบเสมือน "เครื่องยนต์" ที่ทำงานอยู่หลังบ้าน (Server) คอยรับคำสั่ง คำนวณ และส่งค่ากลับ
-   **Frontend (`src/frontend/dashboard.py`):** เปรียบเสมือน "หน้าปัดรถยนต์" ที่ให้ผู้ใช้กดปุ่มสวยๆ โดยที่ผู้ใช้ไม่ต้องรู้กลไกข้างใน
-   **Docker / Scripts:** เครื่องมือช่วยรันให้ทุกอย่างทำงานพร้อมกัน

## 3. วิธีการทดสอบ (How to Test)

### ขั้นตอนที่ 1: เริ่มระบบ
1.  เปิด Terminal (Command Prompt หรือ PowerShell)
2.  ไปที่โฟลเดอร์โปรเจกต์ `AIXX`
3.  พิมพ์คำสั่ง:
    ```bash
    python run_app.py
    ```
4.  รอสักครู่ ระบบจะเปิดหน้าเว็บขึ้นมาให้เองอัตโนมัติ

### ขั้นตอนที่ 2: ทดลองใช้งาน
1.  **Ticker Symbol:** ลองเปลี่ยนชื่อหุ้น เช่น `TSLA` (Tesla), `MSFT` (Microsoft), `BTC-USD` (Bitcoin)
2.  **Timeframe / Risk:** ลองปรับค่าเล่นๆ (ส่วนนี้ในอนาคตจะเชื่อมกับ Logic การคำนวณ)
3.  **กดปุ่ม RUN ANALYSIS:**
    *   สังเกตที่กราฟ (Candlestick): ลองเอาเมาส์ไปชี้ดูราคา
    *   สังเกตที่ Report ด้านล่าง: AI จะเขียนวิเคราะห์ให้อ่าน

### กรณีศึกษา (Test Case)
*   **Case A (มี Internet, ไม่มี API Key):** ระบบจะทำงานได้ปกติ กราฟขึ้น ตัวเลขคำนวณจริง แต่ Report จะบอกว่าเป็น "Offline Mode Simulation"
*   **Case B (ใส่ API Key ถูกต้อง):** ในไฟล์ `.env` ถ้าใส่ Key แล้ว Report จะวิเคราะห์เจาะลึกขึ้นโดยใช้ Gemini จริงๆ
