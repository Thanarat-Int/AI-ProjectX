# คู่มืออธิบายโปรแกรม AI Brain Auto Form (ภาษาไทย)

## ภาพรวมโปรแกรม
AI Brain Auto Form คือโปรแกรมกรอกแบบฟอร์มอัตโนมัติ (เช่น Google Forms) ที่เลียนแบบพฤติกรรมมนุษย์และใช้ระบบ Persona เพื่อให้คำตอบมีความสมจริง สอดคล้องกับบุคลิก และไม่สุ่มมั่วแบบบอทธรรมดา

## โปรแกรมทำอะไรได้บ้าง
- กรอกแบบฟอร์มอัตโนมัติด้วยหลาย Agent พร้อมกัน
- กำหนด/กรองกลุ่มและตำแหน่ง เพื่อคัดเลือก Persona ให้ตรงสายงาน
- เลือกใช้ Persona แบบล็อคต่อ Agent (คนเดิมตอบทั้งรอบ)
- จำทิศทางคำตอบให้สัมพันธ์กัน (เช่น ชอบงานที่บ้านก็จะชอบไปทางนั้นต่อ)
- รองรับคำตอบแบบสเกล (1–5 หรือเห็นด้วย/ไม่เห็นด้วย)
- โหมด Positive-Only (บังคับคำตอบอยู่ช่วง 3–5 และเอนเอียงไปที่ 4–5)
- ห้ามตอบคำตอบบางประโยค (Forbidden Answers)
- ห้ามตอบช่วงอายุบางช่วง (Forbidden Age Rules)
- รองรับ OCR เพื่อดึงคำต้องห้ามจากภาพ (ถ้าใช้ Tesseract)

## โครงสร้างการทำงานโดยย่อ
1) โหลด Persona ตามเงื่อนไขที่ผู้ใช้เลือก (กลุ่ม/ตำแหน่ง)  
2) สุ่มอายุ 18–55 และเพศให้ Persona ในรอบนั้น  
3) เปิดฟอร์มด้วย Selenium แล้วไล่ตรวจคำถามทีละข้อ  
4) คัดตัวเลือกที่ผิดเงื่อนไขออก (Other / Forbidden / Age rules)  
5) คำนวณคะแนนจากบุคลิก + ความสัมพันธ์ของคำถาม  
6) เลือกคำตอบด้วยการสุ่มแบบถ่วงน้ำหนัก (ให้ดูเป็นมนุษย์)  
7) ส่งฟอร์มและวนซ้ำตามจำนวนรอบ

## เทคโนโลยีที่ใช้ (Tech Stack)
- ภาษา: Python 3.13
- UI: CustomTkinter
- Browser Automation: Selenium WebDriver
- Driver Manager: webdriver_manager (ดาวน์โหลด ChromeDriver อัตโนมัติ)
- AI/ML Core: scikit-learn, numpy
- OCR (ตัวเลือก): pytesseract + Tesseract OCR
- Image Handling: Pillow (PIL)
- Build EXE: PyInstaller

## ส่วนที่เกี่ยวกับ AI ใช้อะไรบ้าง
### 1) Unsupervised Learning (การเรียนรู้แบบไม่กำกับ)
ใช้วิธีการจัดกลุ่มข้อความ (Clustering) เพื่อให้ระบบ “เข้าใจบริบทของตัวเลือก” มากขึ้น
- TF-IDF: แปลงข้อความเป็นเวกเตอร์ตัวเลข
- K-Means: จัดกลุ่มคำตอบที่มีความหมายใกล้เคียงกัน
ผลลัพธ์: ตัวเลือกที่อยู่ในกลุ่มเดียวกันจะได้ “ความมั่นใจ” เพิ่ม ทำให้คำตอบดูมีเหตุผลกว่าแบบสุ่มล้วน

### 2) Rule-based + Heuristic Intelligence
ระบบใช้กฎและเหตุผลเชิงตรรกะร่วมกับ Persona เพื่อเลียนแบบมนุษย์จริง
- **Stance Memory**: จดจำทิศทางของความเห็น (เช่น ชอบ/ไม่ชอบ) เพื่อให้ตอบสอดคล้องทั้งฟอร์ม  
- **Keyword Matching**: จับคำถาม/คำตอบกับบริบทและนิสัย  
- **Weighted Random Sampling**: เลือกคำตอบแบบมีน้ำหนัก (ไม่สุ่มแบบเดา)  
- **Positive-Only Constraint**: ถ้าเปิดโหมดนี้ จะบังคับคะแนนให้อยู่ช่วง 3–5

### 3) Soft Constraint (ข้อจำกัดแบบกึ่งล็อค)
ไม่ใช่การบังคับ 100% แต่เป็นการกรองและเพิ่มน้ำหนักให้ตัวเลือกที่ต้องการ เช่น
- ห้ามตอบ 1–2  
- เอนเอียงไปทาง 4–5  
ยังคงคาแรกเตอร์ของ Persona ทำให้ไม่แข็งจนดูเป็นบอท

## ตัวอย่างการตัดสินใจเชิง AI
ตัวอย่างคำถาม: "ฉันรู้สึกผูกพันกับองค์กรที่ทำงานอยู่" (สเกล 1–5)  
1) ระบบตรวจว่าเป็นคำถามเชิงทัศนคติ + เป็นสเกลคะแนน  
2) หา stance ของ persona (เช่น persona แนวจริงจัง อาจเอน 3–4)  
3) ถ้าเปิด Positive-Only จะตัดตัวเลือก 1–2  
4) ให้คะแนนตัวเลือกที่สอดคล้องกับบุคลิก  
5) เลือกแบบถ่วงน้ำหนัก (มีโอกาสออก 4 หรือ 5 มากกว่า 3)

## ภาพรวมโมดูลหลักของโปรแกรม
- `ui.py` จัดการ GUI ทั้งหมด
- `bot.py` ควบคุม Selenium เปิดฟอร์มและคลิกคำตอบ
- `brain.py` ตัดสินใจเลือกคำตอบ (สมองหลัก)
- `data.py` จัดการ Persona, Group/Position, Config
- `learning_core.py` ใช้ K-Means/TF-IDF เพื่อเรียนรู้คำตอบ
- `keyword_weights.py` นิยามคำสำคัญและน้ำหนักคะแนน

## อธิบายเชิงวิทยาศาสตร์ AI อย่างละเอียด
### NLP และ Representation
- ระบบใช้แนวคิด Natural Language Processing (NLP)  
  โดยแปลงข้อความคำตอบให้เป็นเวกเตอร์ด้วย TF-IDF  
  เพื่อให้คอมพิวเตอร์ประเมินความคล้ายของคำตอบได้

### Clustering (K-Means)
- ใช้ K-Means เพื่อจัดกลุ่มคำตอบที่มีความหมายใกล้กัน  
  เช่น กลุ่มคำที่สื่อว่า "เห็นด้วยมาก" หรือ "ไม่เห็นด้วย"
- เมื่อคำตอบใหม่เข้ามา ระบบจะระบุว่าอยู่คลัสเตอร์ใด  
  แล้วเพิ่มคะแนนความมั่นใจเล็กน้อยให้คำตอบนั้น

### Heuristic Reasoning
- ระบบใช้กฎเชิงเหตุผล (Rule-based) เพื่อให้คำตอบดูเหมือนมนุษย์  
- ตรวจคำถามว่าเป็นหัวข้ออะไร (work, culture, happiness ฯลฯ)  
- ใช้ค่า traits / values / interests ของ persona เป็นตัวชี้นำ  
- ถ้าคำถามเชิงลบ จะกลับทิศทางคำตอบให้ตรงบริบท

### Probabilistic Sampling
- หลังคำนวณคะแนน จะไม่เลือกคำตอบแบบตายตัว  
  แต่ใช้การสุ่มแบบถ่วงน้ำหนัก (Weighted Random Sampling)  
  เพื่อให้ยังมี "ความเป็นมนุษย์" และไม่ซ้ำเดิม

### Constraint Satisfaction (Positive Lock)
- เมื่อเปิดโหมด Positive-Only  
  ระบบจะใช้ข้อจำกัด (Constraint) บังคับให้คะแนนอยู่ช่วง 3–5  
  และเพิ่ม Bias ให้ 4–5 มีโอกาสสูงกว่า 3  
  แต่ยังคงการตัดสินใจตามบุคลิก ไม่ใช่สุ่มแข็งๆ

## การเก็บข้อมูลและไฟล์สำคัญ
- `config.json` เก็บค่า URL, loops, filter, โหมดต่างๆ
- `personas.json` รายชื่อ Persona
- `groups.json` กลุ่ม/ตำแหน่งที่กำหนดเอง
- `assets/avatars` เก็บรูปโปรไฟล์ที่ผู้ใช้เพิ่มเอง

## ข้อจำกัดที่ควรรู้
- ขึ้นกับโครงสร้าง HTML ของแบบฟอร์ม (บางรูปแบบอ่านยาก)
- คำถามปลายเปิดจะตอบได้จำกัด ถ้าไม่เปิด LLM
- การตีความคำถามขึ้นกับ keyword และกฎที่ตั้งไว้

## สรุปสั้น
โปรแกรมนี้เป็น Hybrid AI  
คือใช้ทั้ง "การเรียนรู้แบบไม่กำกับ (Unsupervised)" + "ตรรกะและกฎ"  
จึงได้คำตอบที่สมจริง สอดคล้องกับ persona และควบคุมทิศทางได้
