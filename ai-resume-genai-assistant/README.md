# 🤖 AI Resume Screener + GenAI Interview Assistant

AI System that analyzes resumes, classifies skills, matches job descriptions, and generates interview questions using GenAI (LLM).

---

## 🛠 Tech Stack

- Python  
- Scikit-learn / Transformers  
- OpenAI API  
- Streamlit / FastAPI  

---

## 📁 Structure

- `app/` : Backend & Dashboard  
- `model/` : AI Models & Prompts  
- `data/` : Sample resumes & job descriptions  
- `outputs/` : Summary reports
